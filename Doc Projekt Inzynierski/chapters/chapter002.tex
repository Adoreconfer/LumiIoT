\chapter{Projekt}

\section{Wymagania funkcjonalne i niefunkcjonalne}

\textbf{Wymagania funkcjonalne:}
\begin{itemize}
\item Autonomiczna i płynna zmiana jasności świecenia lampy (w 3 zdefiniowanych progach) w zależności od zmian natężenia światła w pomieszczeniu \cite{karta_projektu}.
\item Ciągłe monitorowanie poziomu oświetlenia otoczenia z wykorzystaniem zintegrowanego czujnika natężenia światła (np. fotorezystora) \cite{karta_projektu}.
\item Przetwarzanie i przeliczanie zebranych danych z czujnika za pomocą specjalnego algorytmu wykorzystującego zbiory rozmyte i wnioskowanie (Fuzzy Logic) \cite{karta_projektu}.
\item Prezentacja przetwarzania poprawności danych z czujnika przez algorytm rozmyty z wykorzystaniem wykresów (np. w monitorze portu szeregowego) \cite{karta_projektu}.
\end{itemize}

\textbf{Wymagania niefunkcjonalne:}
\begin{itemize}
\item Oparcie systemu na mikrokontrolerze ESP32 połączonym z modułem oświetleniowym w postaci taśmy LED WS2812 \cite{karta_projektu}.
\item Zapewnienie stabilności działania prototypu oznaczającej pracę bez zawieszania się układu przez co najmniej 1 godzinę ciągłej pracy \cite{karta_projektu}.
\item Eliminacja problemu wizualnego „migotania” lampy na granicy wartości zbiorów rozmytych poprzez zaimplementowanie funkcji uśredniania wyników (np. średnia krocząca z czujnika) oraz właściwe dostrojenie logiki \cite{karta_projektu}.
\item Wykorzystanie w schemacie elektrycznym zewnętrznego zasilacza 5V i kondensatorów ze względu na ryzyko dużego poboru prądu przez taśmę LED \cite{karta_projektu}.
\item Umieszczenie komponentów w bezpiecznej, spasowanej obudowie przygotowanej z wykorzystaniem technologii druku 3D \cite{karta_projektu}.
\item Zmniejszenie zmęczenia oczu użytkownika i ograniczenie zużycia prądu dzięki wprowadzonej optymalizacji \cite{karta_projektu}.
\end{itemize}

\section{Planowane podzespoły lampy}

Poniżej zestawiono podzespoły prototypu lampy oraz ich podstawowe parametry i funkcje.

\begin{itemize}
\item \textbf{Taśma LED COB RGB WS2811} — długość: 2~m; napięcie znamionowe: 24~V DC; moc: 42~W (21~W/m); gęstość: 576 diod/m; sterownik: WS2811; rodzaj: adresowalna taśma RGB COB.
\item \textbf{Zasilacz 24~V / 2~A (48~W)} — napięcie wyjściowe: 24~V DC; maksymalny prąd wyjściowy: 2~A; moc znamionowa: 48~W. Prąd taśmy 42~W przy 24~V: około 1{,}75~A.
\item \textbf{Przetwornica obniżająca XL4015 5~A (DC--DC)} — napięcie wejściowe: 4--38~V DC; regulowane napięcie wyjściowe: 1{,}2--36~V DC; maksymalny deklarowany prąd wyjściowy: 5~A. Przeznaczenie: obniżenie napięcia z szyny 24~V dla układu sterującego. 
\item \textbf{Pojemnościowy przycisk dotykowy TTP223B} — napięcie zasilania: 2{,}5--5~V DC; wyjście: cyfrowe SIG; funkcja: obsługa dotykowa lampy.
\item \textbf{Enkoder obrotowy EC11P12-L20} — typ: EC11P12-L20; rozdzielczość: 12 impulsów/obrót; funkcja: wybór i regulacja koloru świecenia taśmy LED.
\end{itemize}

Taśma LED jest zasilana napięciem 24~V, a ESP32 napięciem 5~V. Sygnał sterujący taśmą należy podłączyć zgodnie z wymaganiami interfejsu WS2811.

\subsection*{UC01 — Automatycznie dostosuj jasność}
\textbf{Aktor główny:} Użytkownik lampy.\\
\textbf{Cel:} Automatyczne dostosowanie jasności taśmy LED do natężenia światła w otoczeniu.\\
\textbf{Warunki początkowe:} Lampa jest zasilana i działa w trybie automatycznym; czujnik światła jest dostępny.\\
\textbf{Warunek końcowy — sukces:} Jasność taśmy zostaje ustawiona na podstawie aktualnego pomiaru.\\
\textbf{Warunek końcowy — niepowodzenie:} Przy niepoprawnym pomiarze system zachowuje ostatnią poprawną jasność.

\textbf{Przebieg główny:}
\begin{enumerate}
\item System mierzy natężenie światła.
\item System filtruje pomiar i przekazuje go do algorytmu Fuzzy Logic.
\item Algorytm wyznacza docelową jasność.
\item ESP32 aktualizuje jasność taśmy LED.
\end{enumerate}
\textbf{Scenariusz alternatywny A1 — niepoprawny pomiar:} System pomija aktualizację jasności i zachowuje ostatnią poprawną wartość.

\subsection*{UC02 — Ustaw kolor świecenia}
\textbf{Aktor główny:} Użytkownik lampy.\\
\textbf{Cel:} Wybór i regulacja koloru taśmy LED za pomocą enkodera obrotowego.\\
\textbf{Warunki początkowe:} Lampa jest zasilana; enkoder i taśma LED są gotowe do pracy.\\
\textbf{Warunek końcowy — sukces:} Taśma LED wyświetla wybrany kolor.\\
\textbf{Warunek końcowy — niepowodzenie:} Kolor pozostaje bez zmian, jeśli sygnał enkodera nie zostanie poprawnie odczytany.

\textbf{Przebieg główny:}
\begin{enumerate}
\item Użytkownik obraca enkoder.
\item ESP32 odczytuje kierunek obrotu i aktualizuje wybrany kolor.
\item ESP32 przesyła dane sterujące do taśmy LED.
\item Taśma LED wyświetla ustawiony kolor.
\end{enumerate}
\textbf{Scenariusz alternatywny A1 — niepoprawny sygnał enkodera:} System odrzuca sygnał i pozostawia dotychczasowy kolor.

\subsection*{UC03 — Obsłuż dotykowo lampę}
\textbf{Aktor główny:} Użytkownik lampy.\\
\textbf{Cel:} Sterowanie lampą za pomocą przycisku pojemnościowego TTP223B.\\
\textbf{Warunki początkowe:} Lampa jest zasilana; wyjście SIG modułu jest podłączone do wejścia ESP32.\\
\textbf{Warunek końcowy — sukces:} System wykonuje funkcję przypisaną do dotknięcia przycisku.\\
\textbf{Warunek końcowy — niepowodzenie:} Stan lampy nie zmienia się, jeśli sygnał dotyku nie zostanie odebrany.

\textbf{Przebieg główny:}
\begin{enumerate}
\item Użytkownik dotyka przycisku.
\item TTP223B przekazuje sygnał cyfrowy SIG do ESP32.
\item ESP32 rozpoznaje sygnał i wykonuje przypisaną funkcję.
\item System aktualizuje stan lampy.
\end{enumerate}
\textbf{Scenariusz alternatywny A1 — brak sygnału:} ESP32 nie wykrywa zmiany SIG; lampa pozostaje w dotychczasowym stanie.
